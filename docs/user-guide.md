## 2. 中英双语切换系统

在顶栏右上角设有语言切换器：**`[EN / 中文]`**。

1. **即时切换**：点击按钮即可在英文与中文之间毫秒级切换，无需重新加载页面。
2. **深度本地化覆盖**：
   - **元素名称**：全量支持标准中文译名与拼音注音（如 `氢 qīng`、`氦 hài`、`锂 lǐ`）。
   - **属性词汇**：密度、熔点、沸点、电负性、共价半径、电离能等 50+ 物理/化学参数。
   - **分类体系**：碱金属、过渡金属、锕系等化学系列。
   - **百科释义与术语表**：元素百科介绍与专业化学词条解释。
3. **状态记忆**：您的语言选择会自动保存至浏览器 `LocalStorage`，下次打开依然生效。

## 3. 宇宙环境音与交互音效系统

本项目配备了基于 **Web Audio API** 原生程序化实时合成的声效引擎，具备零网络开销、纯净高解析度的特点。

### 开启与调节音效
1. 点击顶栏右上角的声音图标（🔊），展开**音频控制面板**。
2. **宇宙背景音 (BGM - Cosmic Drone)**：
   - 开关：点击即可开启/关闭舒缓空灵的深空低音与九和弦漂移声景。
   - 音量滑块：可无极调节背景音大小。
3. **交互音效 (SFX - Sound Effects)**：
   - 开关：控制鼠标悬停、点击、模式切换的声音反馈。
   - 音量滑块：调节按键与泛音响度。

### 音频特色机制
- **原子序数映射泛音**：当您的鼠标滑过周期表上的任意元素单元格时，音频引擎会根据该元素的原子序数（$Z = 1 \sim 118$）映射到对应的五声音阶谐波频率，发出宛如敲击水晶般的泛音共振。
- **浏览器 Autoplay 保护兼容**：为遵循现代浏览器安全规范，若首次加载未发出声音，只需在页面任意位置点击一下即可平滑淡入。

## 4. 周期表三大视图模式

通过顶部工具栏，可在三种视角之间随心切换：

### ① Colors（色彩分类模式）
- **默认模式**：按 IUPAC 规范将 118 种元素归类为 11 大化学系列（如碱金属、碱土金属、过渡金属、稀有气体等）。
- **底部图例联动**：底部常驻系列色卡；鼠标悬停在某个分类标签上时，周期表上相应类别的所有元素将高亮显示，其余变暗，便于快速对比。

### ② Photos（实物标本模式）
- **真实矿物与单质标本**：每个周期表格子内将渲染该元素真实的实物高清图片（如纯金颗粒、紫黑色碘晶体、发光氖气放电管等）。
- **身临其境**：直观感受化学元素在自然界和实验室中的物理质感。

### ③ Heatmaps（多维热力图模式）
点击 `Heatmaps` 下拉菜单，可选择 9+ 项核心物理化学参数：
- **熔点 (Melting Point)**
- **沸点 (Boiling Point)**
- **密度 (Density)**
- **原子量 (Atomic Weight)**
- **原子半径 (Atomic Radius)**
- **电负性 (Electronegativity)**
- **宇宙丰度 (Universe Abundance)**
- **地壳丰度 (Crust Abundance)**
- **半衰期 (Half Life)**

> **提示**：选择属性后，周期表将自动根据数值大小渲染平滑渐变热力色彩，并在底部展示对应的色阶刻度尺与极值范围。

## 5. 元素详情卡片深度交互

在周期表上点击任意元素卡片（例如点击 **`Fe` 铁** 或 **`Au` 金**），屏幕中央将展开多维详情弹窗，包含三个专业标签页：

### 标签页 1：Info（综合参数与动态模型）
- **基本概览**：原子序数、相对原子质量、所属周期与族、中文名、拼音、电子排布式。
- **2D Bohr 原子模型**：
  - 由 HTML5 Canvas 实时渲染，中心为发光原子核与质子/中子信息。
  - 同心圆环展示各层电子公转轨道（K, L, M, N, O, P, Q）。
  - 各轨道上的电子按角速度平滑公转，可直观观察价电子分布。
- **热力学蜡烛温度计 (Candle Thermometer)**：
  - 显示熔点与沸点区间，标注常温 (25°C / 298.15K) 下所处的物理相态（固态/液态/气态）。
  - 支持 **°C（摄氏度）**、**K（开尔文）**、**°F（华氏度）** 自由点击切换换算。
- **可见光发射光谱 (Spectres)**：展示该元素在受激状态下的特征谱线带。
- **全属性列表**：包含晶体结构类型、导电率、热导率、磁学分类、第一电离能、电负性、共价半径、同位素种类等详尽数据。

### 标签页 2：Photo（高分辨率摄影与多形态）
- 展示元素在实验室或宏观世界的大幅高清标本摄影。
- 标注照片版权与摄影师署名。
- 支持同素异形体/不同形态切换（如碳元素的石墨形态、金刚石形态等）。

### 标签页 3：3D（Three.js 三维晶体与原子点阵）
- 基于 WebGL 的实时 3D 晶体点阵展示。
- **鼠标自由交互**：
  - 按住鼠标左键拖拽：360° 自由旋转模型。
  - 滚动鼠标滚轮：平滑放大/缩小。
  - 按住鼠标右键拖拽：平移视角。
- **日间 / 夜间光照模式切换 (Day / Night)**：可切换黑夜科幻发光材质或白天高亮科研光照渲染。

## 6. 智能化学输入与方程式配平求解

顶部的 **Smart Field** 不仅是一个搜索栏，更是一台内置线性代数内核的微型化学计算器。

### ① 元素与物质快速检索
- 输入元素符号：如输入 `Fe`、`Au`、`U`。
- 输入中文名：如输入 `铁`、`金`、`水`、`浓硫酸`。
- 输入拼音：如输入 `tie`、`jin`。
- 周期表会自动过滤并对匹配项进行聚焦高亮。

### ② 化学方程式配平器 (Balance)
内置**高斯消元算法 (Gaussian Elimination)**，可自动求解化学计量数：

**输入格式规则**：
- 反应物与生成物之间使用 `=` 或 `->` 连接。
- 分子之间使用 `+` 连接。
- 大小写可智能容错，角标数字直接输入即可（如 `h2 + o2 = h2o`）。

**典型配平示例**：
```text
H2 + O2 = H2O                        -> 2H₂ + O₂ = 2H₂O
Fe + Cl2 = FeCl3                     -> 2Fe + 3Cl₂ = 2FeCl₃
C2H5OH + O2 = CO2 + H2O              -> C₂H₅OH + 3O₂ = 2CO₂ + 3H₂O
KMnO4 + HCl = KCl + MnCl2 + Cl2 + H2O -> 2KMnO₄ + 16HCl = 2KCl + 2MnCl₂ + 5Cl₂ + 8H₂O
```
输入后点击搜索栏右侧的 **`Balance (配平)`** 按钮，系统将伴随科幻提示音瞬间给出整数化学计量配平结果。

### ③ 反应求解器 (Solve)
输入一种或多种反应物，点击 **`Solve (求解)`** 按钮，系统将在内置反应库中检索匹配的已知化学反应，自动给出生成物和完整的反应方程式。

### ④ 快捷分子芯片 (Quick Chips)
搜索栏下方常驻快捷分子标签（如 `H₂O`、`NaOH`、`H₂SO₄`、`C₂H₅OH` 等），点击即可快速填入，免去手动打字的繁琐。

## 8. 常见问题与故障排查 (FAQ)

### Q1: 页面打开后为什么没有听到背景音乐？
> **解答**：这是现代浏览器（Chrome、Edge、Safari 等）的 **Autoplay 策略安全限制**。当用户尚未与网页产生任何交互时，浏览器会禁止脚本静默发声。您只需要在网页任意空白处点击一下，或点击顶栏的声音图标，背景音就会自动平滑淡入。

### Q2: 如何在本地或局域网其他设备（如手机/平板）上访问？
> **解答**：运行 `./scripts/dev.sh` 时，开发服务器默认绑定至 `0.0.0.0`。在控制台输出的“Network: http://<你的局域网IP>:5173”地址，可以直接用同一 Wi-Fi 下的手机或平板浏览器扫描打开访问。

### Q3: 3D 视图出现黑屏或卡顿是什么原因？
> **解答**：3D 视图依赖设备的 WebGL 硬件加速。请确保您的浏览器已开启硬件加速（以 Chrome 为例：设置 -> 系统 -> 使用图形加速）。

### Q4: 如何在生产服务器上部署？
> **解答**：
> - **静态托管**：运行 `./scripts/build.sh`，将打包生成的 `dist/` 文件夹上传至任意 Web 服务器（如 Nginx、Apache、Vercel、Netlify、GitHub Pages）。
> - **Docker 容器化**：执行 `./scripts/deploy.sh docker` 即可一键在 `8080` 端口运行 Nginx 容器服务。
